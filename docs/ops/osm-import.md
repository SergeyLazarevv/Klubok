# Импорт мест на карту из OpenStreetMap

Как загрузить и обновлять заправки, кафе, достопримечательности и другие места карты из выгрузок OpenStreetMap. Решение и устройство — [ADR-0014](../adr/0014-osm-local-import.md).

Две команды бинарника `klubok`:

| Команда | Что делает | Когда запускать |
|---|---|---|
| `osm-update` | Скачивает выгрузки стран с Geofabrik или только новые дневные дифы к ним, фильтрует нужные места и сливает их в таблицу `pois`: новые добавляет, изменённые обновляет, пропавшие удаляет | Первый раз вручную, потом по крону раз в неделю |
| `poi-enrich` | Загружает описания и фото мест из Wikidata, Википедии и Wikimedia Commons | По крону сразу после `osm-update` |

После импорта карта берёт места внутри загруженных стран из своей базы мгновенно, без обращений к Overpass. Вне загруженных стран всё работает как раньше, через Overpass.

## 1. Подготовка

**osmium-tool** — утилита для работы с файлами OSM:

```bash
sudo apt install osmium-tool
osmium --version   # нужна 1.14 или новее
```

Если osmium установлен не в `PATH`, укажите путь в `KLUBOK_OSMIUM`.

**Диск.** Выгрузки хранятся постоянно, к ним применяются дифы. Для всех регионов по умолчанию нужно около 7 ГБ, плюс столько же временно во время обработки самого большого региона (Россия, 4 ГБ).

**Память.** osmium во время фильтрации и выгрузки занимает до нескольких гигабайт: на Казахстане пик был 2,2 ГБ. Для России закладывайте больше. Если на сервере мало памяти, запускайте импорт ночью, когда API не нагружен.

**База.** Миграции должны быть применены: `make migrate`. Справочник аэропортов (`make import-places`) нужен для слоя «парковки у аэропортов».

## 2. Настройки

Всё необязательно, задаётся в `.env` в корне проекта:

| Переменная | По умолчанию | Что это |
|---|---|---|
| `KLUBOK_OSM_DIR` | `data/osm` | Где хранить выгрузки (папка в `.gitignore`) |
| `KLUBOK_OSM_REGIONS` | 13 регионов, см. ниже | Регионы Geofabrik через запятую |
| `KLUBOK_OSMIUM` | `osmium` | Путь к osmium |
| `KLUBOK_OSM_MAX_LAG` | `30` | Если выгрузка отстала больше чем на столько дневных дифов, скачать её заново целиком |
| `KLUBOK_GEOFABRIK_URL` | `https://download.geofabrik.de` | Адрес Geofabrik или зеркала |
| `KLUBOK_ENRICH_LIMIT` | `5000` | Сколько мест обогащать за запуск крона |

Регионы по умолчанию и размер выгрузок (октябрь 2026):

| Регион | Размер | Регион | Размер |
|---|---|---|---|

Имя региона — путь на [download.geofabrik.de](https://download.geofabrik.de) без `-latest.osm.pbf`: например, `europe/montenegro`.

## 3. Первый запуск

Начните с маленькой страны, чтобы убедиться, что всё работает:

```bash
make osm-update ARGS="--regions asia/armenia"   # ~40 секунд; Казахстан — ~1 минута
```

Затем загрузите все регионы. Первый раз это долго: основное время уходит на скачивание России.

```bash
make osm-update
make poi-enrich ARGS="--limit 1000"
```

Без `make` можно запускать бинарник напрямую: `backend/bin/klubok osm-update`. Тогда переменные из `.env` нужно загрузить самому.

## 4. Команды и флаги

### `osm-update`

```
klubok osm-update [--regions r1,r2] [--full]
```

- `--regions` — обновить только перечисленные регионы. По умолчанию все из `KLUBOK_OSM_REGIONS`.
- `--full` — скачать выгрузки заново, не применяя дифы. Нужен, если локальный файл повреждён.

Что происходит с каждым регионом:

1. Сверяет номер дифа в локальном файле с последним на Geofabrik.
2. Если файла нет или он сильно отстал — скачивает выгрузку целиком. Если отстал немного — скачивает недостающие дневные дифы и накладывает их (`osmium apply-changes`). Если всё актуально и уже загружено в базу — **ничего не делает** (меньше секунды).
3. Фильтрует нужные теги (`osmium tags-filter`) и выгружает места в GeoJSON (`osmium export`).
4. Классифицирует места по слоям и загружает их во временную таблицу.
5. Сливает с `pois`: новые добавляет, изменённые (по хешу полей) обновляет, неизменённые **не трогает**, пропавшие из выгрузки удаляет. Если у места поменялась ссылка на Википедию или фото, описание будет загружено заново.
6. Сохраняет границы региона (`osm_regions`) и пишет строку в журнал `osm_imports`.

Регионы обрабатываются по очереди. Ошибка в одном (например, Geofabrik недоступен) не мешает остальным, но команда завершится с ненулевым кодом. Повторный запуск безопасен. Два одновременных запуска невозможны: второй сразу завершится с сообщением «osm-update уже запущен».

### `poi-enrich`

```
klubok poi-enrich [--limit 2000] [--max-age-days 90] [--pause 300ms]
```

- Берёт места со ссылками на Википедию, Wikidata или Commons, у которых описания ещё нет или оно старше `--max-age-days`. Сначала достопримечательности и природа.
- Для каждого находит описание (первые предложения статьи) и фото (уменьшенная копия с Commons, автор и лицензия).
- `--pause` — пауза между местами, чтобы не нагружать Wikimedia. Около 1,3 секунды на место с учётом запросов, то есть 5000 мест — примерно 2 часа.
- Места, до которых крон ещё не дошёл, обогащаются при первом открытии карточки, как и раньше.

## 5. Крон

Скрипт [`deploy/cron/osm-weekly.sh`](../../deploy/cron/osm-weekly.sh) запускает `osm-update`, затем `poi-enrich`, пишет лог в `data/logs/osm-ГГГГ-ММ-ДД.log` и удаляет логи старше 90 дней.

```bash
crontab -e
# понедельник, 03:30
30 3 * * 1  /path/to/klubok/deploy/cron/osm-weekly.sh
```

Скрипт сам переходит в корень проекта и читает `.env`. Бинарник должен быть собран (`make build`), либо укажите путь в `KLUBOK_BIN`. Еженедельный запуск при актуальных выгрузках занимает минуты: скачиваются только дифы за неделю.

## 6. Как проверить результат

Журнал запусков:

```sql
SELECT region, mode, sequence, features, created, updated, deleted,
       round(duration_ms / 1000.0) AS sec, finished_at
FROM osm_imports ORDER BY id DESC LIMIT 20;
```

`mode`: `full` — скачана выгрузка целиком, `diffs` — применены дифы, `unchanged` — новых дифов не было.

Сколько мест по слоям:

```sql
SELECT osm_region, layer, count(*) FROM pois
WHERE source = 'extract' GROUP BY 1, 2 ORDER BY 1, 3 DESC;
```

Какие регионы загружены:

```sql
SELECT region, sequence, imported_at FROM osm_regions ORDER BY region;
```

## 7. Слои

| Слой (`layer`) | Что попадает |
|---|---|
| `fuel` | Заправки; виды топлива в `tags` (`fuel:lpg`, `fuel:diesel`, `fuel:octane_95`…) |
| `charging` | Зарядки для электромобилей |
| `food` | Кафе, рестораны, фастфуд с названием (кафе у трассы — тот же слой, отбираются по месту на карте) |
| `rest` | Площадки отдыха, придорожные сервисы, туалеты |
| `border` | Пункты пропуска на границе |
| `car_service` | Автосервисы и шиномонтаж |
| `parking` | Парковки **в 3 км от аэропортов** |
| `attraction` | Музеи, смотровые площадки, замки, крепости, монастыри; другие исторические места — только со статьёй или фото |
| `nature` | Пляжи, водопады, вершины, парки, заповедники — **только со статьёй или фото** |
| `useful` | Аптеки, вокзалы, автостанции; банкоматы и обмен валют — только за границей |

Правило: любое туристическое место (`tourism`, `historic`, `natural`, `leisure`) со статьёй в Википедии или фото на Commons попадает на карту, даже если его типа нет в списке. Кроме отелей и подобного.

Поле `category` (`fuel`, `food`, `attraction`, `other`) — грубая группа для текущего API карты. Новые слои (`other`) появятся в интерфейсе вместе с переключателями слоёв.

## 8. Частые вопросы

**Как добавить страну?** Допишите её в `KLUBOK_OSM_REGIONS` и запустите `make osm-update ARGS="--regions africa/morocco"`.

**Как убрать страну?** Уберите её из `KLUBOK_OSM_REGIONS`. Её места останутся в базе, пока не удалите их вручную:

```sql
DELETE FROM pois WHERE source = 'extract' AND osm_region = 'africa/egypt';
DELETE FROM osm_regions WHERE region = 'africa/egypt';
```

и файлы `data/osm/africa-egypt.*`.

**«osmium не найден».** Установите `osmium-tool` или укажите путь в `KLUBOK_OSMIUM`.

**Geofabrik недоступен или оборвалась загрузка.** Файлы скачиваются во временный файл и подменяются только целиком: оборванная загрузка не портит выгрузку. Запустите команду ещё раз.

**Выгрузка повреждена** («Could not detect file format», ошибки чтения PBF). `make osm-update ARGS="--regions <регион> --full"`.

**Объекты на границе стран.** Выгрузки соседних стран пересекаются, одно место может быть в двух. В базе оно хранится один раз, с последним обработанным регионом.

**Лицензия.** Данные OpenStreetMap — ODbL: на карте должна быть подпись «© OpenStreetMap» (она есть). Фото с Commons показываются с автором и лицензией.
