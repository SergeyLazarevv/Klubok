# 2. Глоссарий

| Термин | Значение |
|---|---|
| **Дом (Home)** | Точка отправления пользователя: город из профиля |
| **Точка (Place)** | Любой объект справочника: город, аэропорт, ж/д вокзал, автостанция |
| **Хаб (Hub)** | Транспортная точка, откуда начинается «дальняя» часть маршрута: аэропорт, вокзал, автостанция |
| **Направление (Destination)** | Город, куда хочет попасть пользователь |
| **Плечо (Leg)** | Одна часть маршрута одним видом транспорта: машина Самара → Уральск, рейс URA → ALA |
| **Вариант (Option)** | Полный маршрут туда и обратно: набор плеч и итоговая стоимость |
| **Полная стоимость (Total cost)** | Сумма всех расходов группы на вариант: билеты, топливо, парковка, платные дороги, багаж, сборы |
| **Стоимость на человека** | Полная стоимость, делённая на число путешественников |
| **Радиус поиска** | Максимальное расстояние от дома до хаба, куда пользователь готов ехать на машине |
| **Лимит за рулём** | Максимум часов, которые пользователь готов провести за рулём в одну сторону |
| **Привязка машины (Car anchor)** | Хаб, где осталась машина; обратный маршрут обязан вернуться в него |
| **Базовая цена (Baseline)** | «Обычная» цена направления: медиана за последние 60 дней |
| **Горячее предложение (Deal)** | Текущая цена заметно ниже базовой (по умолчанию на 30% и более) |
| **Самостоятельная стыковка (Self-transfer)** | Пересадка между билетами, купленными отдельно; риск опоздания несёт пользователь |
| **Источник (Provider)** | Внешний API, откуда берутся цены или расстояния |
| **Котировка (Quote)** | Цена от источника на конкретный маршрут и даты с моментом получения |
