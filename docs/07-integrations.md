# 7. Внешние интеграции

## 7.1. Travelpayouts — цены на авиабилеты (MVP)

Решение: [ADR-0006](adr/0006-travelpayouts-fares.md).

- **Что даёт:** Aviasales Data API — цены из кэша поисков пользователей Aviasales; бесплатный доступ по токену после регистрации.
- **Авторизация:** заголовок `X-Access-Token: <token>` (или параметр `token`).
- **Свежесть:** данные хранятся до 7 дней; цены в рублях на момент попадания в выдачу.
- **Сжатие:** отправлять `Accept-Encoding: gzip, deflate`.
- **Партнёрские ссылки:** нужен `marker` (ID партнёра) — добавляется к ссылке на покупку.

Эндпоинты, которые планируем использовать `[сверить по актуальной документации]`:

| Эндпоинт | Для чего |
|---|---|
| `GET /aviasales/v3/prices_for_dates` | Самые дешёвые билеты по направлению на месяц, туда-обратно, с пересадками — **основной для поиска MVP** ✅ проверено. Без `destination` — все направления из города («Куда угодно», ADR-0020) ✅ проверено |
| `GET /aviasales/v3/grouped_prices` | Цены, сгруппированные по датам — календарь цен (v2) |
| `GET /aviasales/v3/get_latest_prices` | Последние найденные цены — горячие предложения (v2) |
| `GET /v1/city-directions` | Популярные направления из города — топ на главной (v2) |
| `GET /data/ru/cities.json`, `/data/ru/airports.json` | Справочники городов и аэропортов |

Что выяснилось при подключении (2026-10-12):
- **На точные даты данных часто нет** (KUF ⇄ ALA на 20–26 ноября — 0 результатов), а за месяц — десятки вариантов. Поэтому запрос идёт по месяцу (`departure_at=YYYY-MM`), а пользователь выбирает диапазон дат (`date_from` — не дальше 3 месяцев вперёд, где в кэше ещё достаточно цен; диапазон — до 60 дней); если диапазон захватывает несколько месяцев, запрашиваются все они. Фильтрация по датам и длительности — на нашей стороне. Узкий диапазон (1–2 дня) может вернуть пусто — это ограничение источника, а не ошибка.
- Без `return_at` в ответ попадают поездки с возвращением в следующем месяце.
- В качестве `origin` принимаются коды городов (MOW → SVO, DME, VKO в ответе) и аэропортов; мы запрашиваем по коду города, а ответ раскладываем по `origin_airport`.
- `price` — за одного взрослого, в рублях. Дата находки цены — в параметре `search_date=ddmmyyyy` внутри `link`.
- Ссылка на покупку: `https://www.aviasales.ru{link}&marker={marker}` `[сверить: засчитываются ли переходы в партнёрке]`.
- Лимит: заголовок `x-rate-limit: 600` (запросов в минуту).
- Не ставить вручную `Accept-Encoding` в Go — иначе `net/http` не распакует gzip.

Ограничения и риски:
- Цены кэшированные → показываем «от N ₽» и время находки.
- По редким направлениям данных может не быть → честно показываем «нет данных», а не «нет рейсов».
- Поиск в реальном времени (Flight Search API) требует отдельной заявки и объёма трафика — рассматриваем после роста аудитории.

## 7.2. VK ID — вход (MVP)

Решение: [ADR-0007](adr/0007-auth.md).

- Протокол: OAuth 2.1 Authorization Code + **PKCE (S256)** — обязательно.
- Поток: бэкенд генерирует `state` и `code_verifier` → редирект на VK ID → callback с `code`, `state`, `device_id` → обмен кода на токены (с `code_verifier` и `device_id`) → получение профиля (id, имя, email если разрешён) → наша сессия.
- `code_verifier` и `state` хранятся в Redis на 10 минут, привязаны к cookie браузера.
- От VK храним только `provider_user_id`; токены VK не храним (не нужны после входа).
- Домен и параметры эндпоинтов: `[сверить по документации VK ID на dev.vk.com — встречаются id.vk.com и id.vk.ru]`.
- Порядок: VK ID подключаем **последним шагом MVP**, когда будет домен; до этого вход только по email.
- Нужно: создать приложение в кабинете VK ID, указать доверенный redirect URI (`https://<домен>/api/v1/auth/vk/callback`; для локальной разработки — отдельный).

## 7.3. Маршрутизация на машине (MVP)

Решение: [ADR-0009](adr/0009-road-routing.md).

- **OSRM** table-сервис: `GET {KLUBOK_OSRM_URL}/table/v1/driving/{lon,lat;...}?sources=0&annotations=distance,duration`.
- **OSRM** route-сервис — линия дороги для карты: `GET {KLUBOK_OSRM_URL}/route/v1/driving/{lon,lat};{lon,lat}?overview=simplified&geometries=polyline6`. Кэш — `road_distances.geometry`; при недоступности — прямая между точками.
- Разработка — публичный демо-сервер (по умолчанию), продакшен — свой экземпляр.
- Кэш — `road_distances`, бессрочно. При недоступности — оценка по прямой × 1,3 (помечается `approximate`).
- Пересечение границы определяем по стране хаба; время на КПП и страховка — из `border_rules`.
- Платные дороги (М-11, М-12 и т.п.): пока не учитываем, в v2 — справочник участков `[открыто]`.

Тайлы карты — `tile.openstreetmap.org`, только для разработки; для продакшена нужен свой источник ([ADR-0012](adr/0012-trip-map.md)).

### Места на карте

Решение: [ADR-0013](adr/0013-map-pois-osm.md).

- **Overpass API** (`KLUBOK_OVERPASS_URL`, по умолчанию `overpass-api.de`; можно несколько через запятую): `POST /api/interpreter`, запрос по прямоугольникам вокруг кусков маршрута, `out center tags`.
- Кэш — `pois` + `poi_scans` (30 дней). Ошибка источника → `502`, область не помечается загруженной.
- Продакшен — импорт выгрузки OSM вместо Overpass `[открыто: когда]`.
- **Wikidata / Википедия / Wikimedia Commons** (MediaWiki API, без ключа, `User-Agent` с контактом по их правилам): описание и фото достопримечательностей при первом открытии карточки, результат — в `pois`.

## 7.3a. Отели и экскурсии

- **Отели — Островок**, см. [ADR-0015](adr/0015-hotels-ostrovok.md): ссылка на поиск с городом и датами, партнёрская через Travelpayouts Links API (`TRAVELPAYOUTS_TRS`); ETG Affiliate API — позже.
- **Квартиры и дома — Суточно.ру**: ссылка на поиск с городом, датами и гостями (Россия и 11 стран), партнёрская тем же способом; API — по заявке после запуска. **Авито** — раздел «Квартиры посуточно» (только Россия, без дат).
- **Экскурсии** (проверено 2026-10-12, не подключено): в Travelpayouts есть программы с API —
  - **Трипстер**: 10 % с экскурсий, 8 % с билетов в музеи; API — города, экскурсии по городу, карточка экскурсии, отзывы, инкрементальные обновления (`updated_after`); токен через `obtain_token`; документация — в партнёрском кабинете. Сильнее всего по России и СНГ, есть и зарубежье.
  - **Sputnik8**: 10 %, API — страны, города, экскурсии; статья в справке Travelpayouts старая, примеры могут не работать.
  - **WeGoTrip** (аудиогиды): 20–30 %, API — туры, города, отзывы.
  - Ссылки на экскурсии нужно делать через инструменты Travelpayouts, иначе продажи не засчитываются. У каждого бренда свои требования к площадке `[проверить в кабинете]`.

## 7.3c. Погода
**Open-Meteo** ([ADR-0022](adr/0022-weather.md)) — без ключа, бесплатно для некоммерческого использования, CC BY 4.0 (ссылка на источник под погодой обязательна).
- Прогноз — `api.open-meteo.com/v1/forecast`, 16 дней по дням: `weather_code`, максимум/минимум, осадки, вероятность осадков; `timezone=auto` — даты местные для точки. Последний день иногда без кода погоды.
- «Обычно в эти дни» — `archive-api.open-meteo.com/v1/archive`, 5 прошлых календарных лет одним запросом (~55 КБ, ~1 с; у архива задержка несколько дней, поэтому текущий год не берём).
- Кэш Redis по сетке 0,1°; свежесть проверяется при чтении: прогноз — 6 часов, норма — 30 дней; источник недоступен — отдаём устаревшее со `stale`.
- При коммерческом запуске — платный тариф с ключом или свой экземпляр (открытый код).

## 7.7. Общие правила для адаптеров

- Каждый источник — отдельный пакет в `internal/providers/<name>`, реализующий общий интерфейс.
- Таймауты, повторы с экспоненциальной задержкой (только для идемпотентных запросов), circuit breaker.
- Ответы источников кэшируются в Redis.
- Секреты — только из переменных окружения, не в репозитории.
- Для тестов — записанные ответы (fixtures), без походов в сеть.
