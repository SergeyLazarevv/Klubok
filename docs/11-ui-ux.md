# UI/UX и дизайн-система

Как выглядит и ведёт себя интерфейс Клубка на телефоне и на десктопе. Документ — источник правды для новых экранов и для переделки старых; решение о переходе зафиксировано в [ADR-0025](adr/0025-design-system-v2.md).

Ориентиры по уровню — Linear, Vercel, Raycast, Stripe: спокойные нейтральные поверхности, один акцент, тонкие рамки, мягкие тени, быстрая и сдержанная анимация.

## 1. Принципы

1. **Телефон — главный экран.** Каждый экран сначала проектируется на 375 px (проверка на 320 px), десктоп — расширение, а не наоборот.
2. **Сначала решение, потом подробности.** Карточка варианта отвечает на «сколько и как долго», план поездки — по «Подробнее» (см. сценарий результатов в [03-requirements](03-requirements.md)).
3. **Цена — всегда итог на группу.** Никаких «на человека» и «поровну на N».
4. **Пользователь выбирает сам.** Интерфейс показывает варианты (ночёвки, остановки), но не принимает решений за человека.
5. **Карта — пастельный слой, интерфейс — современный.** Мультяшная палитра живёт только внутри MapLibre-стиля; панели, кнопки и карточки — на токенах из раздела 3.
6. **Одна система.** В компонентах нет «магических» hex-цветов, теней и длительностей — только токены.

## 2. Стек и как с ним согласованы требования

Приоритет у используемых технологий. Где требование к стилю расходится со стеком — решение в правом столбце.

| Требование | Стек | Как делаем |
|---|---|---|
| Inter/Geist, системный стек | `@fontsource-variable/inter` уже подключён | Inter Variable + системный фолбэк; Geist не добавляем |
| Палитра в CSS-переменных, HSL | Tailwind v4 `@theme inline`, имена токенов shadcn (`--primary`, `--muted`…) | Шкалы `--neutral-50…950`, `--accent-50…950` в HSL; семантические токены shadcn ссылаются на шкалы. Имена shadcn не меняем — компоненты из `components/ui` продолжают работать |
| `prefers-color-scheme` | `@custom-variant dark (&:is(.dark *))` | Класс `.dark` на `<html>` ставит инлайн-скрипт до отрисовки: «как в системе» по умолчанию + ручной выбор. Токены переопределяются под `.dark` |
| Брейкпоинты 375 / 768 / 1024 / 1280 | Tailwind: `sm 640`, `md 768`, `lg 1024`, `xl 1280` | Добавляем `xs = 375px`; в новом коде `sm` не используем, переключение таб-бар → шапка переносим с 640 на 768 |
| Иконки inline SVG | `@lucide/vue` — это и есть inline SVG-компоненты | Только Lucide; эмодзи и символы-иконки (☆) из текста убираем |
| IntersectionObserver + stagger | `@vueuse/core`, `tw-animate-css` | Директива `v-reveal` на одном общем observer'е (раздел 6.3); вход оверлеев — классы `animate-in` из tw-animate-css |
| aria, focus-trap | Reka UI | Диалоги, листы, поповеры, комбобоксы — только через примитивы Reka, свою доступность не пишем |
| Без `!important` | — | Переопределения — через `@layer` и порядок каскада; `tailwind-merge` в `cn()` решает конфликты классов |
| Скругления 10–16 px | Сейчас `--radius: 1rem`, карточки `rounded-3xl` (24 px) | Поле/кнопка 12, карточка/лист 16; пилюли (`rounded-full`) — только для чипов, сегментов и таб-бара |

## 3. Токены

Всё в [style.css](../frontend/src/style.css). Компоненты используют только семантические токены (`bg-card`, `text-muted-foreground`, `shadow-md`), шкалы — для редких оттенков (`bg-accent-50`).

### 3.1 Цвет

Нейтральная шкала — холодный серо-голубой (тон 215), не «чистый» серый: рядом с синим акцентом выглядит цельно. Акцент — нынешний синий `#0b57d0` (= `hsl(217 90% 43%)`, шаг 600). Чистые `#000`, `#fff` для текста и насыщенные «кислотные» цвета не используем; белый допустим только как поверхность карточки в светлой теме.

```css
:root {
  /* Нейтральная шкала: фон, поверхности, рамки, текст */
  --neutral-50:  213 45% 98%;
  --neutral-100: 213 43% 96%;
  --neutral-200: 214 30% 91%;
  --neutral-300: 214 22% 83%;
  --neutral-400: 215 14% 65%;
  --neutral-500: 216 11% 47%;
  --neutral-600: 217 13% 36%;
  --neutral-700: 218 17% 27%;
  --neutral-800: 220 21% 18%;
  --neutral-900: 222 26% 11%;
  --neutral-950: 224 32% 7%;

  /* Акцент: действия, выбранное, перелёт */
  --accent-50:  214 100% 97%;
  --accent-100: 216 95% 94%;
  --accent-200: 217 92% 91%;
  --accent-300: 217 89% 82%;
  --accent-400: 217 90% 66%;
  --accent-500: 217 90% 54%;
  --accent-600: 217 90% 43%;   /* фирменный синий */
  --accent-700: 217 90% 33%;
  --accent-800: 219 85% 25%;
  --accent-900: 220 80% 18%;
  --accent-950: 217 90% 15%;

  /* Смысловые цвета: только шаги 100 (фон тега) / 600 (иконка, текст) / 700 (текст на 100) */
  --road-100: 33 100% 92%;   --road-600: 31 100% 45%;   --road-700: 28 100% 34%;
  --success-100: 138 55% 90%; --success-600: 138 69% 30%; --success-700: 138 69% 22%;
  --danger-100: 4 80% 94%;    --danger-600: 4 71% 41%;    --danger-700: 4 70% 32%;
  --warning-100: 45 100% 90%; --warning-600: 38 92% 42%;  --warning-700: 32 90% 30%;
}
```

Семантические токены (имена shadcn сохраняются):

| Токен | Светлая | Тёмная | Где |
|---|---|---|---|
| `--background` | neutral-50 | neutral-950 | фон страницы |
| `--card`, `--popover` | `0 0% 100%` | neutral-900 | карточки, листы, меню |
| `--foreground` | neutral-900 | neutral-100 | основной текст |
| `--muted` / `--secondary` | neutral-100 | neutral-800 | подложки, чипы, скелетон |
| `--muted-foreground` | neutral-600 | neutral-400 | вторичный текст (контраст ≥ 4.5:1 в обеих темах) |
| `--border` | `neutral-950 / 0.08` | `0 0% 100% / 0.08` | рамки 1 px |
| `--input` | `neutral-950 / 0.16` | `0 0% 100% / 0.14` | рамки полей |
| `--primary`, `--cta`, `--flight` | accent-600 | accent-400 | кнопка действия, перелёт |
| `--cta-hover` | accent-700 | accent-300 | |
| `--accent` / `--accent-foreground` | accent-100 / accent-950 | accent-900 / accent-100 | выбранное, активная вкладка |
| `--ring` | accent-500 | accent-400 | фокус |
| `--road` | road-600 | `31 100% 60%` | машина: линии, иконки |
| `--success`, `--destructive` | *-600 | *-600 светлее на 15% | |

Правила:
- Прозрачность — через модификатор Tailwind (`bg-primary/10`), а не новыми токенами.
- Тег «самый дешёвый» — `bg-success-100 text-success-700`, «самый быстрый» — `bg-accent-100 text-accent-800`; хардкод вроде `bg-[#c4eed0]` заменяется.
- Цвет никогда не единственный носитель смысла: у тега есть текст, у линии на карте — иконка в легенде.

### 3.2 Типографика

Inter Variable, `font-feature-settings: "cv11", "ss01"` (прямая «1» и открытые формы) для всего; `tabular-nums` — для цен, времени, дат в таблицах.

Флюидная шкала через `clamp()` — заголовок растёт плавно от 320 до 1280 px без брейкпоинтов:

| Токен | Размер | Высота строки | Трекинг | Где |
|---|---|---|---|---|
| `--text-display` | `clamp(2rem, 1.4rem + 2.6vw, 3.5rem)` | 1.1 | −0.03em | заголовок главной («Куда поедем?») |
| `--text-h1` | `clamp(1.75rem, 1.4rem + 1.5vw, 2.5rem)` | 1.15 | −0.025em | заголовок страницы |
| `--text-h2` | `clamp(1.375rem, 1.2rem + 0.75vw, 1.75rem)` | 1.25 | −0.02em | секция, город в карточке |
| `--text-h3` | `clamp(1.125rem, 1.05rem + 0.3vw, 1.25rem)` | 1.35 | −0.01em | подзаголовок, этап плана |
| `--text-price` | `clamp(1.5rem, 1.3rem + 0.9vw, 2rem)` | 1.1 | −0.02em | итоговая цена, `font-semibold tabular-nums` |
| `text-base` | 1rem (16 px) | 1.5 | 0 | основной текст, **поля ввода** (меньше 16 px — iOS зумит при фокусе) |
| `text-sm` | 0.875rem | 1.45 | 0 | метаданные, кнопки |
| `text-xs` | 0.75rem | 1.4 | 0.01em | подписи, теги; меньше 12 px не используем (сейчас в таб-баре 11 px — поднять) |

- Длинный текст (путеводитель, описания мест, пустые состояния) — `max-w-[65ch]`, межстрочный 1.6.
- Начертания: 400 текст, 500 кнопки и метки, 600 заголовки и цены. 700+ не используем — выглядит «как в 2000-х».
- Названия городов — `min-w-0 truncate` в одну строку в карточках, перенос — в заголовках экранов.

### 3.3 Пространство — 8pt

Базовый шаг Tailwind — 4 px, поэтому сетка соблюдается выбором чётных шагов: `2, 4, 6, 8, 10, 12, 16, 20, 24` (8…96 px). Шаг 1 (4 px) — только зазор «иконка — текст» и между строкой и её подписью.

| Что | Телефон | ≥ 768 | ≥ 1280 |
|---|---|---|---|
| Поля экрана | 16 | 24 | 32 (контейнер `max-w-7xl` = 1280) |
| Внутренний отступ карточки | 16 | 24 | 24 |
| Между карточками в списке | 12 | 16 | 16 |
| Между секциями страницы | 40 | 56 | 80 |
| Между полями формы | 12 | 16 | 16 |

«Воздух» важнее плотности: если на экран не помещается — сворачиваем (свёрнутая строка поиска, «Подробнее»), а не ужимаем отступы.

### 3.4 Форма: радиусы, рамки, тени, стекло

**Радиусы:** `--radius: 0.75rem` (12 px). Поле, кнопка, сегмент — 12; карточка, поповер, лист, диалог — 16 (`rounded-xl`); иконка-плашка — 10; чип, сегментированный контрол, индикатор вкладки, бейдж — `rounded-full`.

**Рамки:** 1 px `ring-1 ring-border` (тонкая, полупрозрачная). Толстых рамок нет; выделение выбранного — `ring-primary/40` + фон `accent-50`, а не 2 px бордер.

**Тени** — многослойные, окрашены в тон нейтральной шкалы, не в чёрный:

```css
:root {
  --shadow-xs: 0 1px 2px hsl(var(--neutral-950) / 0.05);
  --shadow-sm: 0 1px 2px hsl(var(--neutral-950) / 0.04), 0 2px 6px hsl(var(--neutral-950) / 0.04);
  --shadow-md: 0 1px 2px hsl(var(--neutral-950) / 0.04), 0 4px 12px hsl(var(--neutral-950) / 0.06),
               0 12px 24px -8px hsl(var(--neutral-950) / 0.08);
  --shadow-lg: 0 2px 4px hsl(var(--neutral-950) / 0.04), 0 12px 32px -4px hsl(var(--neutral-950) / 0.10),
               0 24px 64px -16px hsl(var(--neutral-950) / 0.14);
  /* Свечение главной кнопки при наведении */
  --shadow-cta: 0 1px 2px hsl(var(--accent-700) / 0.3), 0 6px 16px -4px hsl(var(--accent-600) / 0.45);
}
.dark {
  /* В тёмной теме тень почти не видна — глубину даёт светлая кромка сверху и более светлая поверхность */
  --shadow-sm: inset 0 1px 0 hsl(0 0% 100% / 0.04), 0 1px 2px hsl(0 0% 0% / 0.4);
  --shadow-md: inset 0 1px 0 hsl(0 0% 100% / 0.05), 0 8px 24px -6px hsl(0 0% 0% / 0.5);
  --shadow-lg: inset 0 1px 0 hsl(0 0% 100% / 0.06), 0 24px 48px -12px hsl(0 0% 0% / 0.6);
}
```

Уровни: карточка в покое — `sm`, при наведении — `md`; плавающая панель над картой, свёрнутый поиск — `md`; лист, диалог, меню — `lg`. Сейчас тени заданы по месту (`shadow-[0_8px_40px_…]`) — заменяются токенами.

**Стекло (blur-подложки):** шапка, таб-бар, свёрнутая строка поиска, панели над картой.

```css
/* Полупрозрачная поверхность поверх контента или карты */
@utility surface-glass {
  background: hsl(var(--glass) / 0.72);
  backdrop-filter: blur(16px) saturate(180%);
  @supports not (backdrop-filter: blur(1px)) {
    background: hsl(var(--glass));
  }
}
/* --glass: светлая — 0 0% 100%, тёмная — var(--neutral-900) */
```

**Градиенты** — едва заметные, не «радужные»:
- главная кнопка: `linear-gradient(180deg, accent-500, accent-600)` + `inset 0 1px 0 hsl(0 0% 100% / 0.16)` — объём без плоскости;
- шапка главной: радиальное пятно `accent-100 → transparent` за заголовком, 30–40 % прозрачности;
- линия плана поездки: `flight → road` по этапам;
- фото-шапки карточек «Куда угодно»: снизу `neutral-950 / 0.6 → transparent` под текст.

### 3.5 Иконки

Lucide, размеры 16 (в тексте, кнопках `sm`), 20 (кнопки, таб-бар), 24 (пустые состояния, плашки). Толщина линии единая — `stroke-width: 1.75` (по умолчанию у Lucide 2 — грубовато для Inter). Декоративные иконки — `aria-hidden="true"`, у кнопки-иконки обязателен `aria-label`. Смысловые цвета иконок: перелёт — `text-flight`, машина — `text-road`, остальное — `text-muted-foreground`.

## 4. Адаптивность

### 4.1 Брейкпоинты

```css
@theme {
  --breakpoint-xs: 23.4375rem; /* 375 */
  /* md 768, lg 1024, xl 1280 — значения Tailwind по умолчанию */
}
```

| Диапазон | Устройство | Компоновка |
|---|---|---|
| 320–374 | маленькие телефоны | одна колонка, поля 16, всё должно влезать без горизонтальной прокрутки |
| `xs` 375–767 | телефоны | одна колонка, нижний таб-бар, листы снизу, детали — полноэкранный TripScreen |
| `md` 768–1023 | планшет, узкий ноутбук | шапка с вкладками вместо таб-бара; формы в 2 колонки; листы → центрированные диалоги |
| `lg` 1024–1279 | ноутбук | список + боковая колонка (карта / план) |
| `xl` ≥ 1280 | десктоп | контейнер 1280 по центру, поля 32 |

### 4.2 Навигация

Разделов четыре (Поиск, Куда угодно, Карта, Избранное), поэтому бургер не нужен ни на одном размере: всё видно сразу, это быстрее.

- **< 768:** тонкая шапка 56 px (логотип + кнопка профиля/настроек) и **нижний таб-бар** 64 px + `safe-area-inset-bottom`, `surface-glass`, рамка сверху. Активная вкладка — пилюля `bg-accent` за иконкой, пилюля переезжает между вкладками (`transform`, 200 ms). Подписи 12 px.
- **≥ 768:** шапка 64 px, `surface-glass`, `sticky top-0`; вкладки по центру (иконка + подпись), профиль справа. Активная — `bg-muted` + `aria-current="page"`.
- Если разделов станет больше пяти — лишние уходят в меню профиля, а не в бургер.
- На экранах с полноэкранной картой (Куда угодно, Карта) шапка на телефоне скрыта, её место занимает плавающая кнопка «назад/профиль» над картой.

### 4.3 Пальцы

- Тап-таргет ≥ 44×44. Видимая кнопка может быть меньше (иконка 32 px в плотном ряду) — тогда утилита `hit` расширяет зону касания. Между соседними целями ≥ 8 px.
- Главное действие экрана на телефоне — внизу, в зоне большого пальца: кнопка «Найти» на всю ширину, высота 52, над таб-баром (`sticky bottom-[calc(var(--tabbar-h)+16px)]`) когда форма длиннее экрана.
- Ховер-подсказки (`title`) не работают на телефоне → нажатие открывает поповер.
- Свайпы только как ускорение, всегда есть кнопка-дубль: удаление в избранном — свайп **и** кнопка в меню, закрытие листа — свайп вниз **и** «Готово».
- Системный жест «назад» закрывает лист/полноэкранный план (как уже сделано в TripScreen через `?trip=`).

### 4.4 Проверка на 320 px

Чек-лист для каждого экрана: нет фиксированных ширин > 288 px; у гибких детей `min-w-0`; сетки — `grid-cols-[minmax(0,1fr)]`; цены `whitespace-nowrap`, названия городов — `truncate`; сегментированный контрол не вылезает (подписи сокращаются: «На машине» → «Машина» до `xs`); календарь в листе помещается 7 колонок по 40 px; горизонтальные ленты (чипы, погода, места по пути) прокручиваются с `scroll-snap` и затуханием по краю; ландшафт телефона — лист не выше `90dvh`.

## 5. Компоненты

### 5.1 Кнопки

| Вариант | Вид | Когда |
|---|---|---|
| `primary` | градиент accent-500→600, белый текст, `shadow-sm` | одно главное действие на экран: «Найти», «Купить билеты» |
| `secondary` | `bg-muted` | второстепенное рядом с главным |
| `outline` | `bg-card ring-1 ring-input` | «Подробнее», фильтры |
| `ghost` | без фона | действия в шапке, тулбары |
| `destructive` | `bg-danger-100 text-danger-700` | удалить |
| `link` | текст accent | переходы внутри текста |

Размеры: `sm` 36 (только ≥ 768 или с `hit`), `md` 44 (по умолчанию), `lg` 52 (главное действие на телефоне). Сейчас в `components/ui/button` дефолт — 32 px: поднимаем размеры в cva, а не на местах.

Состояния (обязательно все):

| Состояние | Что меняется |
|---|---|
| hover (только устройства с мышью — `hover:` в Tailwind v4 уже под `@media (hover: hover)`) | фон на шаг темнее; `primary` — `shadow-cta`; карточка-ссылка — `translateY(-1px)` + `shadow-md` |
| active | `scale(0.97)`, тень на уровень ниже; на телефоне это единственный отклик — не пропускать |
| focus-visible | кольцо `ring-2 ring-ring ring-offset-2 ring-offset-background`; только с клавиатуры |
| disabled | `opacity-50`, без тени, `cursor-not-allowed`, `aria-disabled` если кнопка должна оставаться в фокусе с подсказкой |
| loading | спиннер вместо иконки, ширина не прыгает (`min-w` по тексту), `aria-busy="true"`, клик игнорируется |

### 5.2 Поля ввода

Высота 48 на телефоне, 44 на ≥ 768; `text-base`; метка над полем (не плейсхолдер вместо метки); фокус — `ring-2 ring-ring/40` + рамка `ring`; ошибка — рамка `danger-600`, текст под полем, связь `aria-describedby`, `aria-invalid="true"`. Выбор города на телефоне — полноэкранный поиск с недавними и геолокацией; даты — лист с календарём; число путешественников — степпер с кнопками 44 px.


- Радиус 16, `ring-1 ring-border`, `shadow-sm`, паддинг 16 / 24.
- Вся карточка не кликабельна целиком (в ней две кнопки) — фокус по кнопкам, без вложенных интерактивов.
- Раскрытая на десктопе — `ring-primary/40`; на телефоне «Подробнее» открывает TripScreen (стрелка ›, а не ˅).
- Цена — справа и крупно на любой ширине ≥ 375; на 320 — под названием.

### 5.4 План поездки

Вертикальная лента этапов: плашка 32 px с иконкой этапа (цвет по виду транспорта), соединительная линия 2 px; заголовок этапа `text-h3`, время и цена справа `tabular-nums`. Детали этапа (погода, места по пути, жильё) — горизонтальные ленты карточек 160–200 px с `scroll-snap-type: x mandatory`. На ≥ 1024 план — правая липкая колонка рядом со списком; на телефоне — полноэкранный TripScreen с липкой шапкой (назад · маршрут · в избранное · поделиться).

### 5.5 Листы и диалоги

Один компонент `ResponsiveSheet` поверх Reka `Dialog`:
- **< 768** — лист снизу: радиус сверху 16, ручка 36×4 `bg-neutral-300`, `max-h-[90dvh]`, `overscroll-contain`, нижний отступ `safe-area`; закрывается свайпом вниз, тапом по фону, «назад».
- **≥ 768** — диалог по центру, ширина 560, или поповер у кнопки, если содержимое короче 5 строк.
- Фон: `bg-neutral-950/40` + `backdrop-blur-sm`. Фокус ловится внутри, по закрытию возвращается на кнопку-вызов (Reka делает это сам).

Для «Куда угодно» — **лист с точками фиксации** над картой: 120 px (ручка + сегмент Самолёт | На машине), 50 %, 90 %. На ≥ 1024 вместо листа — плавающая панель слева 400 px, `surface-glass shadow-lg`, отступ 16 от краёв.

### 5.6 Сегменты, чипы, вкладки

Сегментированный контрол (Самолёт | На машине, Всё/Самолёт/Машина): контейнер `bg-muted rounded-full p-1`, выбранный — `bg-card shadow-sm`, бегунок переезжает (`transform`, 200 ms), роли `radiogroup`/`radio` (Reka `ToggleGroup type="single"`). Чипы фильтров — высота 36 + `hit`, выбранный `bg-accent text-accent-foreground` с галочкой.

### 5.7 Обратная связь

- **Тосты:** снизу над таб-баром (на ≥ 768 — снизу слева), по одному, 4–6 с, с «Отменить» для обратимых действий; `role="status"`.
- **Ошибки:** рядом с тем, что их вызвало; на весь экран — только если экран без данных бесполезен.
- **Пустые состояния:** иконка 24 в плашке 48 `bg-accent-50 text-accent-600`, заголовок h3, одно предложение `max-w-[65ch]`, одна кнопка.
- **Загрузка:** скелетон повторяет форму будущего содержимого (4 карточки результатов, ленты погоды). Поиск — не блокирующий экран: свёрнутая строка + скелетоны + шаги («Ищем перелёты… → Считаем дорогу…») в `aria-live="polite"`. Спиннер — только внутри кнопки.

## 6. Анимация

### 6.1 Токены

```css
:root {
  --ease-standard: cubic-bezier(0.4, 0, 0.2, 1);   /* почти всё */
  --ease-emphasized: cubic-bezier(0.2, 0, 0, 1);   /* листы и панели: быстрый старт, мягкая посадка */
  --dur-fast: 150ms;   /* цвет, фон, рамка, ховер */
  --dur-base: 200ms;   /* нажатие, переключатели, бегунок сегмента, раскрытие чипа */
  --dur-slow: 300ms;   /* появление секций, листы, раскрытие карточки */
}
```

В `@theme` они же — `--ease-standard`, `--default-transition-duration: 150ms`, `--default-transition-timing-function: var(--ease-standard)`, чтобы `transition` в Tailwind сразу брал правильные значения.

### 6.2 Что анимируем

- Только `transform`, `opacity`, `box-shadow`, цвета. Никогда — `height`, `width`, `top` (раскрытие — через `grid-template-rows: 0fr → 1fr`).
- Микроанимации кнопок: active `scale(.97)` за 100 ms, hover тень за 150 ms.
- Выход быстрее входа (выход ×0.75).
- Ничего не анимируется дольше 300 ms и ничего не повторяется бесконечно, кроме скелетона и спиннера.
- Цена при пересчёте (остановки, даты) — короткий кросс-фейд числа, без «прокрутки цифр».

### 6.3 Появление секций — `v-reveal`

Секции ниже первого экрана и элементы списков появляются со сдвигом вверх на 8–12 px и проявлением, со ступенькой 40 ms (не больше 6 ступенек — дальше без задержки). Первый экран (форма поиска, цены) не прячем никогда — это ухудшает LCP.

```ts
// lib/reveal.ts — один IntersectionObserver на всё приложение, а не по одному на элемент
const io = typeof IntersectionObserver === 'undefined' ? null : new IntersectionObserver(
  (entries) => {
    for (const e of entries) {
      if (!e.isIntersecting) continue
      e.target.classList.add('is-revealed')
      io!.unobserve(e.target) // показываем один раз
    }
  },
  { rootMargin: '0px 0px -10% 0px', threshold: 0.12 },
)

/** v-reveal="i" — i задаёт ступеньку задержки в списке */
export const vReveal: Directive<HTMLElement, number | undefined> = {
  mounted(el, { value }) {
    if (!io) return // без observer'а элемент просто виден
    el.style.setProperty('--i', String(Math.min(value ?? 0, 6)))
    el.classList.add('reveal') // скрываем только когда JS точно отработает
    io.observe(el)
  },
  unmounted(el) { io?.unobserve(el) },
}
```

```css
.reveal {
  opacity: 0;
  transform: translateY(12px);
  transition: opacity var(--dur-slow) var(--ease-standard), transform var(--dur-slow) var(--ease-standard);
  transition-delay: calc(var(--i, 0) * 40ms);
}
.reveal.is-revealed { opacity: 1; transform: none; }

@media (prefers-reduced-motion: reduce) {
  /* Без движения: только мгновенное появление */
  .reveal { transform: none; transition: opacity 1ms; transition-delay: 0ms; }
}
```

### 6.4 `prefers-reduced-motion`

Глобально: длительности переходов → 1 ms, скелетон без отблеска (уже так), листы появляются без выезда (только прозрачность), бегунки сегментов прыгают сразу, `scroll-behavior: auto`, карта — `flyTo` заменяется на `jumpTo`. Tailwind-варианты `motion-safe:` / `motion-reduce:` — для точечных случаев.

## 7. Тёмная тема

- Режимы: «Как в системе» (по умолчанию), «Светлая», «Тёмная» — переключатель в профиле, выбор в `localStorage`.
- Инлайн-скрипт в `index.html` до загрузки приложения ставит `.dark` на `<html>`, иначе будет вспышка белого; он же слушает `matchMedia('(prefers-color-scheme: dark)')` в режиме «как в системе».
- `<meta name="color-scheme" content="light dark">` и два `theme-color` с `media` — чтобы системные полосы, скроллбары и поля браузера совпадали с темой.
- Поверхности светлеют с высотой: фон neutral-950 → карточка 900 → лист/поповер 800. Тени почти не работают — глубину дают поверхность и светлая кромка.
- Карта: пастельный стиль MapLibre получает тёмный вариант палитры (приглушённые те же цвета, вода neutral-800) — отдельный этап, до него карта остаётся светлой и в тёмной теме.
- Фото не инвертируются; на фото-шапках остаётся тёмный градиент под текст.

## 8. Доступность

- Landmarks: `header`, `nav[aria-label="Разделы"]`, `main`; первая ссылка — «К содержимому» (видна при фокусе).
- `:focus-visible` у всех интерактивных — кольцо из токена `--ring`, `outline` не убирается без замены.
- `aria-current="page"` у активной вкладки; `aria-expanded` + `aria-controls` у «Подробнее»; `aria-pressed`/`role="radio"` у переключателей; `aria-live="polite"` для числа найденных вариантов и пересчёта цены.
- Контраст: текст ≥ 4.5:1, крупный текст и границы контролов ≥ 3:1 — в обеих темах. Проверять при каждом новом токене.
- `@media (prefers-contrast: more)`: `--border` и `--input` плотнее вдвое, стекло непрозрачное.
- Карта: всё, что есть на карте (цены городов, остановки), доступно и списком.
- Масштаб текста до 200 % не ломает раскладку: размеры в `rem`, высоты контейнеров — `min-h`, не `h`.

## 10. Качество кода

- Токены — только в `style.css`; в компонентах нет hex/rgb, теней и длительностей вручную. Проверка: `grep -rnE "#[0-9a-fA-F]{3,6}|rgb\(" frontend/src --include=*.vue` должен находить только стиль карты (`lib/map/*`).
- Варианты компонентов — через `cva` в `components/ui/*`; повторяющиеся сочетания — через `@utility` (`hit`, `surface-glass`), а не копипастой длинных строк классов.
- `!important` и `!`-модификатор Tailwind не используются; конфликты решает `cn()`.
- Каждый ключевой блок шаблона и каждая утилита в CSS — с коротким комментарием «зачем» (как уже принято в проекте).
- Новый экран принимается, если: проверен на 320 / 375 / 768 / 1280, в обеих темах, с клавиатуры, с `prefers-reduced-motion`.

## 11. План перехода

Порядок — от фундамента к экранам; каждый этап — отдельный коммит, приложение остаётся рабочим.

1. **Токены:** шкалы HSL, семантика shadcn поверх них, тени, движение, брейкпоинт `xs`, `surface-glass`, глобальный `prefers-reduced-motion`. Без изменений в компонентах — вид почти не меняется.
2. **Базовые компоненты:** размеры и состояния `Button`, `Input`, сегменты, чипы; `ResponsiveSheet`; `v-reveal`; замена ☆ и прочих символов на Lucide.
3. **Оболочка:** таб-бар/шапка на 768, стекло, пилюля активной вкладки, ссылка «К содержимому».
4. **Тёмная тема:** скрипт темы, `color-scheme`, переключатель в профиле; аудит контраста.
5. **Экраны по очереди:** Поиск и карточки → TripScreen/план → Избранное → Куда угодно (вместе с пользователем, см. ADR-0020).
