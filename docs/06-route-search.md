# 6. Поиск маршрутов и расчёт стоимости

## 6.1. Модель

Задача — найти самые дешёвые варианты поездки **туда и обратно** от дома до направления.

Маршрут представляется как путь в графе:
- **узлы** — дом, хабы (аэропорты, позже вокзалы и автостанции), направление;
- **рёбра** — плечи: машина, самолёт, позже поезд и автобус;
- **вес ребра** — стоимость для всей группы; время в пути — ограничение и второй критерий сортировки.

## 6.2. Алгоритм MVP: «машина + самолёт»

В MVP граф неглубокий (дом → хаб → направление), поэтому достаточно перебора:

```
вход: профиль, направление D, даты dep/ret, N путешественников

1. hubs = аэропорты домашнего города
2. если есть машина:
       hubs += аэропорты в радиусе R от дома (PostGIS ST_DWithin)
       для каждого хаба h не в домашнем городе:
           road(h) = расстояние и время дом → h (кэш road_distances)
           отбросить h, если road(h).duration > лимит за рулём
           отбросить h, если граница и пользователь не разрешил её на машине
3. параллельно для каждого h: quotes(h) = FareProvider.RoundTrip(h, D, dep, ret)
4. для каждой котировки q: option = собрать вариант, посчитать стоимость (6.3)
5. отбросить варианты без загранпаспорта, если требуется
6. сортировать по полной стоимости; оставить лучшую котировку на хаб + топ-20 всего
7. добавить сравнение с лучшим вариантом из домашнего города
```

Машина остаётся у аэропорта вылета, поэтому возврат всегда в тот же хаб: запрос к источнику — round trip `h → D → h`.

## 6.3. Формулы стоимости

Обозначения: `N` — путешественники, `days` — длительность поездки в сутках (`ret − dep + 1`), `km` — расстояние дом → хаб.

**Плечо «машина» (туда и обратно, на всю группу):**

```
fuel    = km × 2 × consumption_l100 / 100 × fuel_price
tolls   = toll × 2
parking = parking_per_day(hub) × days
border  = insurance(страна хаба), если хаб за границей, иначе 0
car     = fuel + tolls + parking + border
```

Цена топлива: `fuel_price_override` из профиля, иначе справочная цена региона дома.

**Плечо «самолёт» (на всю группу):**

```
air = (fare + baggage) × N
```

**Итог:**

```
total      = car + air
per_person = total / N
```

Расходы на машину делятся на всех, билеты умножаются на всех. Поэтому вариант с машиной выгоднее в компании.

## 6.4. Пример

> Цифры условные, для иллюстрации формул.

Профиль: Самара, 2 путешественника, машина 8 л/100 км, АИ-95 по 62 ₽/л, разрешено пересекать границу.
Поездка в Алматы на 7 дней.

| | Из Самары (KUF) | Через Уральск (URA) |
|---|---|---|
| Машина: 330 км × 2 × 8 / 100 × 62 ₽ | — | 3 274 ₽ |
| Парковка: 7 сут × 300 ₽ | — | 2 100 ₽ |
| Страховка авто в Казахстане | — | 1 500 ₽ |
| Билеты туда-обратно: × 2 чел. | 40 000 × 2 = 80 000 ₽ | 10 000 × 2 = 20 000 ₽ |
| **Итого** | **80 000 ₽** | **26 874 ₽** |
| На человека | 40 000 ₽ | 13 437 ₽ |
| Время за рулём | — | ~4 ч + КПП в одну сторону |

Предупреждения для варианта через Уральск: пересечение границы на машине, время на КПП непредсказуемо, нужна казахстанская страховка.

## 6.5. Ранжирование

По умолчанию — по полной стоимости. Дополнительные сортировки:
- по общему времени в пути;
- «с учётом времени»: `total + hours_driving × value_of_hour`, где `value_of_hour` — настройка пользователя `[открыто, v2]`.

## 6.6. Развитие: мультимодальный граф (v3)

Когда появятся поезда, автобусы и самостоятельные стыковки, перебор перестанет работать: маршрут вида «машина → поезд → самолёт → самолёт» имеет много сочетаний.

План:
- граф, зависящий от времени (у рейсов и поездов есть расписание);
- многокритериальный поиск (стоимость, время, число пересадок) по Парето-фронту — алгоритм класса label-setting / RAPTOR-подобный;
- минимальное время на пересадку: 2 ч для самолёт → самолёт с разными билетами, 1,5 ч для поезд → самолёт (+ дорога между вокзалом и аэропортом), настраиваемо;
- ограничение глубины: не более 4 плеч в одну сторону;
- правило привязки машины: если первое плечо — машина до хаба H, последнее плечо обратного маршрута — машина от H.

## 6.7. Свежесть цен

Источник отдаёт кэшированные цены (до 7 дней). Каждый вариант хранит `found_at`; если цене больше 48 ч — показываем предупреждение. Окончательная цена — на сайте продавца.
