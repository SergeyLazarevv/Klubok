# ADR-0001. Фиксировать решения в ADR

**Статус:** Принято · 2026-10-12

## Контекст
Проект начинается с одного разработчика, но планируется коммерческое развитие. Через год будет непонятно, почему выбрано то или иное решение.

## Решение
Каждое значимое техническое решение (стек, хранилище, внешний источник, протокол) оформляется коротким ADR в `docs/adr/`.

## Последствия
- История решений видна в репозитории.
- Небольшие накладные расходы на написание.
