# ADR-0014. Свои данные OSM: импорт выгрузок, слои карты, обновление по крону

**Статус:** Принято · 2026-10-12 · импорт и обогащение реализованы; слои в интерфейсе — следующий шаг. Инструкция — [docs/ops/osm-import.md](../ops/osm-import.md)

## Контекст
Места на карте сейчас берутся из публичного Overpass по запросу ([ADR-0013](0013-map-pois-osm.md)). Первый показ новой дороги или города — 10–40 с, при перегрузке Overpass (504) — ошибка. Слоёв станет 10, запросов — больше. Нужно: мгновенное чтение, предсказуемое обновление по команде из крона и обновление только изменившегося.

## Как часто меняются данные
- **OpenStreetMap** правят непрерывно; Geofabrik публикует выгрузки по странам и **ежедневные дифы** (osmChange). Доля изменившихся за неделю точек наших категорий мала — поэтому обновляем только изменённые строки, а не перезаливаем таблицу. Для мест на карте достаточно **раз в неделю**.
- **Википедия / Wikidata / Commons** (описания и фото) меняются редко: новые места — при обновлении, старые — раз в 90 дней или сразу, если в OSM поменялись ссылки.

## Решение

### 1. Хранение
- Таблица `pois` остаётся единственным местом для чтения. Новые колонки:
  - `layer` — слой карты (см. п. 4), `tags jsonb` — нужные теги OSM (топливо, плата, места…);
  - `source` — `extract` (наш импорт) | `overpass` (запасной путь вне выгрузок);
  - `osm_hash` — хеш значимых полей: по нему обновление трогает только изменившиеся строки;
  - `photo_*`, `description`, `details_at` — как сейчас.
- `osm_imports` — журнал запусков: регион, номер дифа (sequence), время, создано / изменено / удалено, длительность.

### 2. Регионы
- Выгрузки Geofabrik из настройки `KLUBOK_OSM_REGIONS`: Россия, Казахстан и популярные направления — Беларусь, Грузия, Армения, Азербайджан, Узбекистан, Кыргызстан, Турция, ОАЭ, Египет, Таиланд, Вьетнам `[уточнить список]`. Россия ~4 ГБ, всё вместе ~10 ГБ на диске.
- Места вне выгрузок — по-прежнему через Overpass с кэшем на 30 дней (`source = overpass`).

### 3. Обновление — команда `klubok osm-update` (крон: раз в неделю ночью)
1. **Скачать только новое.** Для каждого региона сравнить свой номер дифа с `state.txt` Geofabrik и скачать недостающие дневные дифы (`.osc.gz`, единицы–десятки МБ). Нет базового файла или отстали больше чем на 30 дней — скачать выгрузку целиком.
2. **Применить дифы** к локальному `.osm.pbf`: `osmium apply-changes`.
3. **Отфильтровать** наши теги: `osmium tags-filter` → `osmium export` в GeoJSON Lines (у линий и полигонов — точка на поверхности, `ST_PointOnSurface`).
4. **Загрузить в staging** через `COPY`, посчитать `osm_hash`.
5. **Слить в `pois` одним SQL:**
   - новые → вставить;
   - `osm_hash` изменился → обновить (если поменялись ссылки на Википедию или фото — сбросить `details_at`);
   - не изменился → не трогать;
   - есть в `pois` (`source = extract`), но пропал из всех выгрузок → удалить (объект удалён или потерял теги).
6. **Записать запуск** в `osm_imports`; лог со счётчиками.

Команду можно запускать вручную; повторный запуск без новых дифов ничего не меняет. Блокировка (advisory lock в PostgreSQL) — от двух одновременных запусков.

Отдельно — `klubok poi-enrich` (крон: раз в неделю после `osm-update`): описания и фото для мест со ссылками на Википедию/Wikidata/Commons без `details_at` и для тех, у кого `details_at` старше 90 дней. Пакетно: Wikidata — по 50 элементов за запрос, Commons — по 50 файлов, с паузами по правилам Wikimedia. Ленивая загрузка при открытии карточки остаётся для того, что крон ещё не обработал.

### 4. Слои карты

| Этап | Слой | Теги OSM | Показ |
|---|---|---|---|
| Дорога | Заправки | `amenity=fuel`; фильтр по топливу профиля: `fuel:lpg`, `fuel:diesel`, `fuel:octane_92/95` | вкл |
| Дорога | Зарядки | `amenity=charging_station` | когда в профиле электромобиль |
| Дорога | Кафе у трассы | `amenity=cafe/restaurant/fast_food`, вне городов (дальше ~3 км от центра `place=city/town`) | вкл |
| Дорога | Остановки | `highway=rest_area/services`, `amenity=toilets` | вкл |
| Дорога | КПП | `barrier=border_control` | всегда, если маршрут пересекает границу |
| Дорога | Автосервис | `shop=car_repair/tyres` | выкл |
| Аэропорт | Парковки | `amenity=parking` в 3 км от аэропорта, `fee`, `capacity` | вкл |
| На месте | Достопримечательности | `tourism=attraction/museum/viewpoint/gallery/zoo/theme_park`, `historic=*` (кроме массовых мемориалов) | вкл |
| На месте | Природа и отдых | `natural=beach/waterfall/peak/cave_entrance/spring`, `leisure=park/nature_reserve/beach_resort`, `tourism=picnic_site` — **только если есть фото или статья** (без них слишком много шума) | вкл |
| На месте | Кафе и рестораны | `amenity=cafe/restaurant/fast_food` | вкл |
| На месте | Полезное | `amenity=atm/bureau_de_change` (за границей), `amenity=pharmacy`, вокзалы и автостанции (`railway=station`, `amenity=bus_station`) | вкл |

Правило для фото: **любое место с фото (Wikidata P18 / Commons) храним и показываем**, даже если его тип не в списке выше, но он из туристических категорий (`tourism`, `historic`, `natural`, `leisure`).

### 5. Чтение и кэш
- Запросы — по GiST-индексу в PostGIS (коридор вдоль дороги, радиус), миллисекунды; Redis не нужен.
- HTTP: `Cache-Control: public, max-age=86400` и `ETag` по времени последнего импорта — браузер и будущий CDN не спрашивают повторно.
- Фронтенд: слои загружаются и появляются по отдельности, не ожидая друг друга; кэш в памяти на время сессии (уже есть для дорог).

## Последствия
- Карта мест не зависит от Overpass для основных направлений; любой поиск — мгновенный.
- На сервере нужны `osmium-tool` и ~10 ГБ под выгрузки; первая загрузка — порядка часа, еженедельное обновление — минуты.
- Overpass остаётся только для мест вне выгрузок.
- Лицензия ODbL: на карте уже есть «© OpenStreetMap»; при импорте ничего не меняется.

## Реализация (2026-10-12)

Код: `backend/internal/poi/osmimport` (импорт), `backend/internal/poi/layers.go` (слои), `backend/internal/poi/enrich.go` (обогащение), миграция `00007_osm_import.sql`. Отличия от плана выше:

- **Регион обрабатывается целиком отдельно:** скачать → отфильтровать → staging → слить → удалить пропавшие **этого региона** (`pois.osm_region`). Сбой одного региона не трогает остальные, а запуск с `--regions` не удаляет места других стран. Цена: места убранной из настроек страны удаляются вручную (см. инструкцию).
- **Точка для линий и площадей считается в Go** (середина линии; центр самого большого контура, если он внутри, иначе вершина), а не `ST_PointOnSurface` в PostGIS: одна невалидная геометрия OSM не должна ронять импорт страны.
- **Overpass пропускается, если все прямоугольники запроса лежат внутри границ загруженных выгрузок** (`osm_regions.area` из файлов `.poly` Geofabrik).
- **Номер дифа** хранится в заголовке самой выгрузки (`osmosis_replication_sequence_number`); после наложения дифов он перезаписывается.
- **`category`** оставлена грубой группой для текущего API (`fuel | food | attraction`), места новых слоёв — `other`; слой — в `layer`.
- **`poi-enrich`** — пока по одному месту с паузой (используется тот же код, что и при открытии карточки), сначала достопримечательности и природа. Пакетные запросы к Wikidata по 50 элементов — оптимизация на потом, если 5000 мест в неделю окажется мало.
- **Банкоматы и обмен валют** не берём из выгрузки России (сотни тысяч точек, нужны только за границей).

Замеры на этой машине: Армения (51 МБ) — 39 с первый импорт, 0,8 с запуск без изменений, 8 с с тремя дифами; повторная загрузка неизменного файла — 0 изменённых строк.
