# ADR-0027. Предложения об отдыхе: горящие туры, дома и базы отдыха, подборки

**Статус:** Предложено · 2026-11-08

## Контекст
Хотим показывать в приложении интересные предложения об отдыхе: горящие туры, аренду домов и мест отдыха (турбазы, глэмпинги, кемпинги), подборки «куда поехать». Открытых бесплатных источников с **предложениями и ценами** в России нет: их отдают только партнёрские программы. Открытые данные есть только о самих местах, без цен.

Источники (проверено 2026-11-08):
- **Level.Travel** (Travelpayouts, 3,8 % за первое бронирование, 1,5 % за последующие, cookie 30 дней). Публично доступны виджет направлений, виджет пакета и генератор ссылок. Есть «быстрые ссылки» с городом вылета: самые дешёвые туры из выбранного города. **API и XML-фид туров** (обновляется примерно раз в 30 минут, цену актуализирует метод `api.level.travel/search/actualize`) выдаются только после прямого согласования с Level.Travel. Документация не публичная, у рекламодателя есть лимиты запросов. **`[сверить]`** адрес и условия после ответа на заявку.
- **Travelata** (Travelpayouts / Admitad): горящие туры. XML-фиды и API для партнёров есть, но по запросу у менеджера.
- **Onlinetours** (Travelpayouts): туры, только ссылки.
- **Sletat.ru**: самая полная база туров по туроператорам РФ, но API по договору, обычно для агентств. **`[сверить]`**
- **Суточно.ру** (API по заявке после запуска на домене, см. [ADR-0021](0021-stay-prices.md)), **Островок / ETG** (API по договору, [ADR-0015](0015-hotels-ostrovok.md)), **Tvil.ru** (дома, гостевые дома, базы; есть партнёрская программа, **`[сверить]`** наличие API).
- **Авито**: API для внешних витрин нет, ботам отвечает 429. Только ссылка, как сейчас.
- **Открытые данные без цен:** OSM (`tourism=camp_site|chalet|guest_house|hostel|alpine_hut|caravan_site`, `leisure=resort|beach_resort`; импорт уже есть, [ADR-0014](0014-osm-local-import.md)); реестр классифицированных средств размещения и единый федеральный реестр туроператоров (Минэкономразвития / Ростуризм). **`[сверить]`** формат выгрузок.

## Решение
Три блока, в таком порядке:

1. **Горящие туры на главной.** Город вылета берём из дома пользователя или ближайший к нему город вылета Level.Travel. Источник — Level.Travel через Travelpayouts. Пока нет API: карточки направлений с «быстрой ссылкой» Level.Travel, которую `travelpayouts.Linker` превращает в партнёрскую, без цен. После одобрения заявки — адаптер API/фида за интерфейсом провайдера туров: команда `klubok tours-update` по крону раз в день (по образцу `fares-daily.sh`), таблица предложений, кэш Redis. Цену в карточке перед переходом актуализируем.
2. **Дома и базы отдыха рядом с маршрутом.** Новый слой карты из OSM: кемпинги, турбазы, глэмпинги, гостевые дома, курорты. У точки кнопки «Посмотреть на Суточно / Tvil / Островке» с партнёрской ссылкой. Договоры не нужны.
3. **Подборки** («Выходные за городом до 5 000 ₽» и т. п.): объекты с ценами из выгрузок Островка, Суточно.ру и Tvil (после доступа к API), кэш Redis. До этого подборки собираются из слоя OSM и цен Росстата ([ADR-0021](0021-stay-prices.md)) со знаком «≈».

Сбор данных со страниц сайтов (Авито, Level.Travel, Суточно) не используем: это против правил сайтов.

### Блок 1 — как сделано (2026-11-08)
- Модуль `internal/tours`: интерфейс `Provider` (горящие туры и страница всех туров города), сейчас реализован `LevelTravelLinks`. Это 14 популярных направлений с месяцами сезона: в выдачу попадают первые 6 из тех, что в сезоне, вылет через 3 дня, ночей по направлению (7–10), взрослых до 4.
- Город вылета — ближайший по прямой из 24 крупных городов вылета (`tours.Departures`). Дальше 1000 км (например, за границей) — туров не предлагаем.
- Адреса Level.Travel проверены редиректом с «быстрой ссылки»: старые поддомены городов больше не работают. **`[сверить]`** в браузере, что сайт понимает названия городов вылета (`St.Petersburg`, `Nizhny.Novgorod`, `Rostov-on-Don`, `Mineralnye.Vody` и т. п.).
- `GET /tours/hot` отдаёт карточки со ссылками на `/tours/go`. Там ссылка превращается в партнёрскую через Travelpayouts Links API (тот же `TRAVELPAYOUTS_TRS`, что у Островка) и пересчитывается на сервере, так что внешний адрес клиент не передаёт.
- Интерфейс: компонент `HotTours.vue`. С главной под формой поиска убран (не понравилось), новое место **`[открыто]`**.

## Последствия
- До одобрения API в блоке горящих туров нет цен, только направления и ссылки. Карточка честно говорит «смотреть туры на Level.Travel».
- Заявки на API (Level.Travel, Travelata, Суточно.ру) лучше подавать после запуска на домене: партнёрки смотрят на площадку.
- Партнёрские ссылки требуют ID проекта (`trs`) и подключённой в кабинете Travelpayouts программы Level.Travel.

## Дальше
- Заявка на API Level.Travel (через поддержку Travelpayouts или affiliate@level.travel), затем Travelata как второй источник.
- После решения по каждому блоку оформить отдельный ADR со статусом «Принято».
