# ADR-0004. Vue 3 + PWA для фронтенда

**Статус:** Принято · 2026-10-12

## Контекст
Нужен современный веб-интерфейс, работающий на телефоне без нативного приложения. Предпочтение автора — Vue 3. Мобильное приложение — в перспективе, на том же API.

## Решение
Vue 3 + TypeScript + Vite + Pinia + Vue Router, PWA через `vite-plugin-pwa`. API-клиент генерируется из OpenAPI.

## Последствия
- Установка на домашний экран, офлайн-оболочка, push-уведомления (Android, iOS 16.4+ для установленных PWA).
- UI-кит выбирается отдельно: PrimeVue или Tailwind + свои компоненты `[открыто]`.
