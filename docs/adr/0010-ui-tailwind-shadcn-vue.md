# ADR-0010. Tailwind + shadcn-vue для UI

**Статус:** Принято · 2026-10-12

## Контекст
Нужен современный уникальный вид и Tailwind (выбор автора). Кандидаты на Tailwind: shadcn-vue, Nuxt UI, PrimeVue в unstyled-режиме, Flowbite Vue.

## Решение
**shadcn-vue** поверх **Reka UI** (headless-примитивы с доступностью: диалоги, выпадающие списки, календарь, комбобокс), Tailwind CSS, иконки **Lucide**.

## Обоснование
- Компоненты копируются в проект (`src/components/ui`), а не подключаются пакетом: полный контроль над видом, нет «шаблонного» внешнего вида.
- Есть всё нужное для поиска путешествий: календарь и выбор диапазона дат, комбобокс с автодополнением, карточки, слайдеры (радиус, расход), тосты, тёмная тема.
- Nuxt UI заточен под Nuxt; Flowbite Vue — беднее набор и слабее доступность; PrimeVue unstyled — тяжелее в настройке под Tailwind.

## Последствия
- Обновления компонентов не приходят автоматически — подтягиваем через CLI shadcn-vue при необходимости.
- Дизайн-токены (цвета, радиусы, шрифты) задаём в CSS-переменных Tailwind — единый стиль. Тема — только светлая, нейтральная, в духе Material 3 (решение 2026-10-12, после вариантов «тёплый», «как Aviasales» и «Нить»): белый фон, синий акцент, план поездки лентой этапов по мотивам Layla.ai.
