# ADR-0017. Как добраться внутри города: такси, общественный транспорт, пешком

**Статус:** Принято · 2026-10-14 · прототип API готов, интерфейс и внешние ключи — следующие шаги

## Контекст
После прилёта нужно доехать до жилья по известному адресу (и наоборот — от жилья до аэропорта или вокзала). Пользователь хочет видеть несколько вариантов и выбрать один: такси, автобус, метро, пешком. Позже тот же механизм нужен для «дом → вокзал» в сценарии без машины.

## Что проверено (2026-10-14)

| Источник | Результат |
|---|---|
| Transitous (MOTIS, открытые GTFS) | Работает в Берлине (4 варианта с S-Bahn и U-Bahn), **для Москвы, Алматы, Казани, Стамбула, Тбилиси — 0 маршрутов**: открытых расписаний городского транспорта этих стран нет |
| Photon (адреса OSM) | Без привязки к городу ошибается (Стамбул → Балыкесир); с привязкой — Казань и Стамбул точно; в Алматы дом находится по казахскому названию улицы («Абай даңғылы 10»), по «Абая 10» — другие улицы агломерации |
| OSRM машина / FOSSGIS OSRM пешком | Работают: аэропорт Алматы → центр 24 км, 26 мин; вокзал → центр пешком 3,6 км, 47 мин |
| Ссылки на маршрут: Яндекс Карты (`rtext`, `rtt=auto|mt|pd`), 2ГИС (`/directions/points/lon,lat|lon,lat`, домен страны), Яндекс Go (appmetrica `route`) | Все открывают готовый маршрут |
| 2ГИС Public Transport API | Несколько вариантов маршрута с временем, пересадками и пешими участками; сильнейшее покрытие РФ и Казахстана; демо-ключ на месяц, далее платно `[проверить с ключом]` |
| API прогноза стоимости Яндекс Такси | Цена и время поездки, кнопка Яндекс Go; ключ по анкете партнёра `[проверить с ключом]` |

## Решение
- Модуль `transfer`, эндпоинты `GET /geocode` (адрес рядом с городом) и `GET /transfers` (варианты).
- **Адрес:** Photon с привязкой к городу назначения, отбрасываем результаты дальше 60 км, дома выше улиц, организации в одном доме склеиваются. Пользователь выбирает из нескольких вариантов и при необходимости **ставит точку на карте**; позже — вставка ссылки из Яндекс Карт или 2ГИС (координаты есть в ссылке).
- **Варианты:**
  - *Такси* — расстояние и время по дороге (OSRM). Цена — из API Яндекс Такси, когда будет ключ; до тех пор — «точную цену покажет Яндекс Go» и кнопка вызова с заполненным маршрутом. Больше 4 человек — пометка про минивэн.
  - *Общественный транспорт* — маршруты 2ГИС (несколько вариантов: время, пересадки, пешком), когда будет ключ; до тех пор — кнопки «открыть маршрут в Яндекс Картах / 2ГИС».
  - *Пешком* — если по прямой до 5 км и идти не дольше часа.
  - Варианты сортируются по времени; выбранный сохраняется в поездку (вместе с «блокнотом»).
- Внешние сервисы — за интерфейсами (`transfer.Router`, далее `TaxiPricer`, `TransitPlanner`): ключа нет — вариант остаётся, но в виде ссылки.

## Последствия
- Без ключей пользователь уже видит время и расстояние на такси и в один клик открывает готовый маршрут в привычном приложении.
- Публичные Photon и FOSSGIS OSRM — только для разработки (правила использования, нет SLA); в продакшене — свои экземпляры (Photon на тех же выгрузках OSM, что и места на карте) или платный геокодер.
- Цены на проезд в общественном транспорте пока не считаем: у 2ГИС их нет в маршрутах; нужна таблица тарифов по городам `[открыто]`.
- Аэроэкспрессы и электрички до аэропортов — через API Яндекс Расписаний (см. обсуждение поездов), когда будет ключ.
