# ADR-0005. PostgreSQL + PostGIS + Redis

**Статус:** Принято · 2026-10-12

## Контекст
Нужны: реляционные данные пользователей; геопоиск «все хабы в радиусе N км»; кэш ответов внешних API; rate limiting; временное хранение OAuth-state.

## Решение
- PostgreSQL + PostGIS — основное хранилище; геопоиск через `ST_DWithin` по `geography`.
- Redis — кэш и короткоживущие данные.

## Последствия
- Геопоиск — один SQL-запрос с индексом GiST.
- История цен (v2) поместится в PostgreSQL; при росте — партиционирование по месяцам.
