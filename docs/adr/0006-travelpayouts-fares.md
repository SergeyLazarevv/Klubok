# ADR-0006. Travelpayouts как источник авиацен

**Статус:** Принято · 2026-10-12

## Контекст
Нужны цены на авиабилеты с вылетом из РФ. Варианты: GDS (Amadeus и аналоги) — дорого и малодоступно для небольшого проекта, работа в РФ ограничена; Kiwi — закрыт для новых партнёров и слабо покрывает РФ; Travelpayouts (Aviasales) — бесплатно по токену, хорошее покрытие РФ и СНГ.

## Решение
Travelpayouts Aviasales Data API для MVP. Адаптер реализует общий интерфейс `FareProvider`, чтобы источник можно было заменить или добавить другой.

## Последствия
- Цены кэшированные (до 7 дней) → показываем «от N ₽» и время находки; финальная цена на сайте продавца.
- По редким направлениям данных может не быть.
- Бонус: партнёрские ссылки с `marker` — первый канал монетизации.
- При росте трафика — заявка на Flight Search API (поиск в реальном времени).
