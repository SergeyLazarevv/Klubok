# ADR-0007. Email + VK ID, JWT + refresh-токены

**Статус:** Принято · 2026-10-12

## Контекст
Способы входа: email + пароль и VK ID. Клиенты: PWA, в будущем мобильное приложение.

## Решение
- Email + пароль (argon2id), подтверждение email, восстановление.
- VK ID: OAuth 2.1 Authorization Code + PKCE.
- Сессии: короткий access JWT (15 мин) + refresh-токен (30 дней) с ротацией; в БД хранится хэш refresh. Веб получает refresh в HttpOnly cookie, мобильное приложение — в теле ответа.

## Последствия
- Один механизм для веба и мобильного приложения.
- Повторное использование отозванного refresh → отзыв всей цепочки (защита от кражи).
- Аккаунты VK без email допускаются; email можно добавить позже.
