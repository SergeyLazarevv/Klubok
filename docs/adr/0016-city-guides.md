# ADR-0016. Путеводители по городам: Викигид сейчас, афиша Культура.РФ — после ключа

**Статус:** Принято · 2026-10-13

## Контекст
В «Что посмотреть» были только объекты OpenStreetMap: их много, они не ранжированы («Флагшток» рядом с собором), фото есть у ~22 %. Нужен отбор «что действительно стоит посмотреть», обзор города и (позже) афиша на даты поездки. Пользователь просил не смешивать источники.

Рассмотрены: Рувики (форк Википедии — API отвечает 403, часть статей несвободна, содержание почти как в Википедии), OpenTripMap (OSM + Wikidata + реестр Культура.РФ и рейтинг; бесплатно ~1000 запросов/сутки, условия для коммерции неясны), **Викигид** (путеводитель Wikimedia, CC BY-SA), **PRO.Культура.РФ** (афиша и места России, ключ по договору), открытые данные Минкультуры (ключ после регистрации).

## Решение
### Викигид — сделано
- Статья о городе ищется по названию (`Уральск`, затем `Уральск (город)`); неоднозначные страницы и тёзки дальше 60 км от города отбрасываются.
- Из статьи берутся **обзор** (вступление + начало раздела «Понять») и **места** — шаблоны `{{listing}}`/`{{see}}`/`{{eat}}`…: тип, название, описание, адрес, сайт, часы, цена, координаты, Wikidata, фото с Commons (уменьшенная копия, автор, лицензия).
- **Хранение отдельно от OSM:** `guides` (статья: город, источник, язык, ревизия, обзор, лицензия, когда проверяли) и `guide_listings` (места статьи). `pois` (OSM) не трогается. Новый источник — новое значение `source`, та же схема.
- **Обновление:** при запросе, если статью не проверяли 30 дней. Ревизия та же — только отметка о проверке; изменилась — статья разбирается заново и её места заменяются целиком в одной транзакции. Статьи нет — это тоже запоминается (без повторного поиска 30 дней). Викигид недоступен — отдаётся сохранённое.
- **Показ:** в «Что посмотреть» сначала обзор и места Викигида (`see`, `do`; с фото — первыми) с подписью «По материалам Викигида · CC BY-SA 4.0» и ссылкой на статью, затем «Ещё рядом — по данным OpenStreetMap» без повторов (совпадение по Wikidata или названию).
- API: `GET /places/{id}/guide` (для аэропорта — его город).

### PRO.Культура.РФ — после ключа
- Афиша на даты поездки («Досуг в ваши даты») для городов России. Ключ выдаётся партнёрам по письму на partners@team.culture.ru; документация с этого сервера недоступна (403), поэтому клиент пишем, когда будут ключ и документация. Запасной путь — открытые данные Минкультуры (`opendata.mkrf.ru`, ключ после регистрации).
- Хранение — по тому же принципу, отдельными таблицами (`culture_events`, `culture_places`) со своим `source` и сроком жизни (события — сутки).

## Последствия
- Для крупных и туристических городов «Что посмотреть» становится осмысленным и с фото (Алматы — 97 мест, 31 с фото; Тбилиси — 26 и 18); для малых городов статьи может не быть — остаётся OSM.
- Лицензия CC BY-SA требует подписи источника рядом с данными — она есть на странице.
- Рестораны, жильё и транспорт из Викигида уже хранятся (`eat`, `sleep`, `go`), но пока не показываются `[открыто: где показывать]`.
