# ADR-0015. Отели: Островок — партнёрская ссылка сейчас, API позже

**Статус:** Принято · 2026-10-12

## Контекст
В плане поездки нужен этап «Проживание». Booking.com и Expedia в России не работают; Hotellook (Travelpayouts) закрыт в октябре 2025. Для России и популярных направлений подходит Островок (Emerging Travel Group). Для партнёра это бесплатно: модель — комиссия с бронирований, платить ничего не нужно.

## Решение
**Этап 1 (сделано):** ссылка на поиск Островка с городом, датами и числом гостей.
- Формат: `https://ostrovok.ru/hotel/{страна}/{город}/?dates=ДД.ММ.ГГГГ-ДД.ММ.ГГГГ&guests=N`. Страна — по справочнику ISO → адрес Островка (`hotels/ostrovok.go`), город — английское название в нескольких вариантах написания (`st._petersburg`, `nizhniy_novgorod` — транслитерация Островка), подходящий проверяется запросом и запоминается. Островок отвечает медленно (1–20 с), поэтому проверка ограничена 4 с; не ответил — берётся самый вероятный адрес без запоминания. Города нет — страница страны.
- Партнёрская метка: если задан `TRAVELPAYOUTS_TRS` (проект, к которому в кабинете Travelpayouts подключена программа Островка), ссылка превращается в партнёрскую через Travelpayouts Links API (`POST /links/v1/create`). Без него — обычная ссылка.
- API: `GET /hotels/link` (JSON) и `GET /hotels/go` (302 — для кнопки «Найти отель», чтобы не ждать проверки при показе страницы).

**Квартиры посуточно — Авито (2026-10-13).** Для тех, кто хочет снять частное жильё, а не отель, в «Проживании» вторая строка — раздел «Квартиры посуточно» на Авито в городе назначения (только Россия).
- Формат: `https://www.avito.ru/{город}/kvartiry/sdam/posutochno-ASgBAgICAkSSA8gQ8AeSUg`. Город — русское название по транслитерации Авито (`moskva`, `sankt-peterburg`, `nizhniy_novgorod`, `hotels/avito.go`). Даты и гостей в адрес не передать (фильтры Авито — закрытый формат), их выбирают на сайте.
- Проверить адрес запросом, как у Островка, нельзя: Авито отвечает ботам 429. Город с нестандартным адресом на Авито может не открыться — тогда добавить исключение.
- API: те же `/hotels/link` и `/hotels/go` с `provider=avito` (по умолчанию `ostrovok`); для городов не в России — 404. Партнёрской программы нет.

**Этап 2 (позже):** ETG Affiliate API — цены, фото и рейтинги отелей прямо в плане. Нужны договор с ETG и сертификация интеграции на работающем сайте, поэтому — после выхода в продакшен `[открыто]`.

## Последствия
- Сейчас в плане нет цен и фото отелей — только переход на Островок с правильными датами.
- В мае 2026 сообщалось о возможной покупке бренда Островка Яндексом; платформа остаётся у ETG. Если условия партнёрки изменятся — пересмотреть.
