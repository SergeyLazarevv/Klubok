# ADR-0021. Цена жилья по городам карты: Росстат сейчас, Суточно.ру потом

**Статус:** Принято · 2026-10-17

## Контекст
Пользователь хочет видеть полную стоимость поездки сразу на карте «Куда угодно» ([ADR-0020](0020-explore-anywhere.md)): дорога + жильё. Нужна цена жилья по каждому городу карты (~1130 городов России), храниться в БД и отдаваться через кэш.

Источники (проверено 2026-10-17):
- **API Суточно.ру** через Travelpayouts — реальные предложения квартир, можно честно считать медиану. Выдаётся по заявке, после запуска на домене — пока недоступен.
- **ETG (Островок) Affiliate API** — нужен договор.
- **Hotellook** (Travelpayouts) — закрыт, все адреса отвечают 404.
- **Росстат, ЕМИСС**, показатель 31448 «Средние потребительские цены (тарифы) на товары и услуги»: «Проживание в гостинице 2*/3*/4–5*, хостел — сутки с человека», помесячно по ~300 городам наблюдения и регионам. Открытые данные (CC BY 3.0), публикуются с задержкой ~1,5 месяца.
- Отчёты Домклика и Авито — PDF по десятку городов, без API. Сбор со страниц Авито и Суточно — против правил сайтов.

## Решение
- **Источник сейчас — Росстат, гостиница 3*, сутки с человека.** ЕМИСС не даёт API: берём то же, что загружает таблица на сайте — справочники фильтров со страницы показателя и данные POST-запросом `/indicator/dataGrid.do` (`internal/stay/rosstat.go`). Значение — последний месяц, где цена есть.
- **Город карты → цена:** своя, если Росстат наблюдает город; иначе ближайшего города наблюдения в пределах 250 км (Жигулёвск → Тольятти, Хвалынск → Балаково); иначе средняя по России. Зарубежным городам цены нет. В записи хранится, чья это цена (`basis`), — в карточке это видно. На 2026-10-17: 1130 городов, у 194 своя цена, 32 по средней по России.
- **Хранение и кэш:** таблица `stay_prices` (Wikidata ID города карты → цена, категория, источник, `basis`, месяц). `GET /stay-prices` читает Redis (`klubok:stay-prices:v1`); нет ключа — читает БД и кладёт в Redis на 7 дней (страховка). Команда `klubok stay-update` (cron `deploy/cron/stay-monthly.sh`, раз в месяц) пишет новый расчёт в БД одной транзакцией, удаляет города, которых в нём нет, и **сбрасывает ключ** — следующий запрос заполнит кэш из БД. Недоступный Redis не ломает ответ: данные берутся из БД.
- **На карте:** жильё = цена суток × путешественники × ночи (у перелёта — по датам рейса, у машины — по минимальной длительности поездки) и входит в итог плашки, списка и карточки; переключатель «Учитывать жильё» (по умолчанию включён). В карточке — «Жильё, N ночей ≈ … ₽» и «Средняя цена суток в гостинице 3* — … ₽. Росстат, <месяц>, по данным для г. …».

## Последствия
- Это средняя цена гостиницы 3*, а не медиана посуточных квартир: квартиры обычно дешевле, на курортах в сезон — дороже. Подписываем честно, со знаком «≈».
- «Все варианты» (полный поиск) пока показывает только дорогу — жильё там добавить отдельно.

## Дальше
- После запуска — заявка на API Суточно.ру; новый источник подменяет Росстат в `stay-update` (медиана предложений квартир по городу и датам), остальная цепочка не меняется.
