# ADR-0009. OpenRouteService + кэш, OSRM позже

**Статус:** Предложено · 2026-10-12

## Контекст
Нужны расстояние и время на машине от дома до хабов. Варианты: Яндекс.Маршрутизация (точно, платно), OpenRouteService (бесплатный тариф с лимитами), свой OSRM (бесплатно, но нужен сервер с большим объёмом памяти для подготовки данных РФ).

## Решение
MVP — OpenRouteService с бессрочным кэшем в `road_distances`. Пары «город → хаб» ограничены, поэтому лимитов бесплатного тарифа достаточно. При росте — свой OSRM на данных OpenStreetMap.

## Последствия
- Адаптер за интерфейсом `RoadRouter` — замена без изменения поиска.
- Точность времени в пути без учёта пробок — для межгородских поездок приемлемо.
- Время на КПП не входит в маршрут — берётся из `border_rules`.
