# ADR-0009. OSRM для маршрутов на машине, с кэшем в БД

**Статус:** Принято · 2026-10-12 (первая редакция предлагала OpenRouteService)

## Контекст
Нужны расстояние и время на машине от дома до хабов. Варианты: Яндекс.Маршрутизация (точно, платно), OpenRouteService (бесплатно, нужен ключ, дневные лимиты), OSRM (открытый, есть публичный демо-сервер; в продакшене — свой экземпляр на данных OpenStreetMap).

## Решение
- OSRM, table-сервис: один запрос «дом → все хабы» (пачками по 50 точек).
- Разработка — публичный демо-сервер `router.project-osrm.org` (не для продакшена, но с кэшем запросов мало).
- Продакшен — свой OSRM на выгрузке OSM по России и соседям (`KLUBOK_OSRM_URL`).
- Результат кэшируется в `road_distances` бессрочно.
- Маршрутизатор недоступен → оценка: расстояние по прямой × 1,3, скорость 70 км/ч; такие значения помечаются `approximate` и не кэшируются.

## Последствия
- Ключ и регистрация не нужны.
- Адаптер за интерфейсом `road.Router` — замена без изменения поиска.
- OSRM не учитывает пробки; для межгородских поездок приемлемо. Время на КПП берётся из `border_rules`.
- Для продакшена нужен сервер с ~16+ ГБ RAM на подготовку данных РФ (или готовый образ) — учесть при выборе тарифа.
