# ADR-0002. Go для бэкенда

**Статус:** Принято · 2026-10-12

## Контекст
Кандидаты: Go и PHP. Основная нагрузка — поиск: параллельный опрос многих источников (хабы × направления × даты) с таймаутами, плюс фоновые задачи сбора цен. CRUD-части (кабинет, авторизация) немного. В будущем — единый бэкенд для PWA и мобильного приложения.

## Решение
Go.

## Обоснование
- Конкурентность из коробки: горутины, `context` с таймаутами и отменой — ровно то, что нужно для fan-out запросов к API.
- Фоновые задачи живут в том же бинарнике (`klubok worker`), без отдельной инфраструктуры очередей на старте.
- Один статический бинарник, малое потребление памяти — дешёвый хостинг.
- Строгая типизация упрощает сопровождение алгоритма расчёта.

## Последствия
- CRUD пишется дольше, чем на Laravel; компенсируем генерацией из OpenAPI (`oapi-codegen`) и SQL (`sqlc`).
- Меньше готовых «батареек» (админка, авторизация) — делаем сами, объём небольшой.
