# 3. Функциональные требования

Приоритеты: **MVP** — первая версия; **v2, v3…** — этапы из [Roadmap](10-roadmap.md).

## 3.1. Аутентификация — MVP

| ID | Требование |
|---|---|
| AUTH-1 | Регистрация по email и паролю. Пароль от 8 символов |
| AUTH-2 | Подтверждение email по ссылке из письма. Без подтверждения можно пользоваться поиском, но не сохранять профиль `[открыто]` |
| AUTH-3 | Вход по email и паролю |
| AUTH-4 | Вход и регистрация через VK ID |
| AUTH-5 | Привязка VK ID к существующему аккаунту и наоборот (если email совпадает — предложить связать, а не создавать дубль) |
| AUTH-6 | Восстановление пароля по email |
| AUTH-7 | Выход; выход со всех устройств |
| AUTH-8 | Удаление аккаунта со всеми персональными данными (152-ФЗ) |

## 3.2. Профиль и настройки — MVP

| Поле | Тип | По умолчанию | Примечание |
|---|---|---|---|
| Домашний город | Точка-город | — | Обязателен для поиска; автодополнение |
| Число путешественников | 1–9 | 1 | Билеты × N, расходы на машину делятся на всех |
| Есть машина | да/нет | нет | Включает автомобильные настройки ниже |
| Тип топлива | АИ-92 / АИ-95 / ДТ / газ | АИ-95 | Только при наличии машины |
| Расход, л/100 км | число | 8 | Только при наличии машины |
| Своя цена топлива, ₽/л | число | пусто | Если задано — заменяет справочную |
| Радиус поиска, км | 50–1000 | 100 | Только при наличии машины |
| Лимит за рулём, ч в одну сторону | 1–24 | 6 | Отсекает хабы, до которых дольше |
| Загранпаспорт | да/нет | да | Без него не предлагаем зарубежные направления и хабы |
| Готов пересекать границу на машине | да/нет | нет | Учитывает зарубежные хабы (Уральск и т.п.) |
| Багаж | без / ручная кладь / 1 место | ручная кладь | Влияет на цену билета `[сверить: есть ли в данных]` |

> Замечание: при радиусе 100 км из Самары Уральск (~300+ км по дороге) в поиск не попадёт. Пользователь сам решает, насколько далеко готов ехать; лимит по часам часто удобнее радиуса. Оба ограничения применяются вместе.

## 3.3. Поиск — MVP (простой сценарий)

**Сценарий:** пользователь выбирает направление и даты туда/обратно → видит список вариантов, отсортированный по полной стоимости.

| ID | Требование |
|---|---|
| SRCH-1 | Поиск всегда туда и обратно |
| SRCH-2 | Ввод: направление (город), дата вылета, дата возвращения; число путешественников и «на машине» берутся из профиля, но меняются в форме |
| SRCH-3 | Минимальная длительность поездки — 3 дня (настройка системы) |
| SRCH-4 | Без машины: вылет из аэропортов домашнего города |
| SRCH-5 | С машиной: дополнительно все аэропорты в радиусе и в пределах лимита за рулём; машина остаётся у аэропорта вылета, возврат туда же |
| SRCH-6 | Учитываются рейсы с пересадками (как их отдаёт источник) |
| SRCH-7 | Каждый вариант показывает: плечи, полную стоимость, стоимость на человека, разбивку расходов, общее время в пути, предупреждения |
| SRCH-8 | Предупреждения: пересечение границы на машине, самостоятельная стыковка, устаревшая цена (старше 48 ч) |
| SRCH-9 | Кнопка «Купить» ведёт на сайт продавца по партнёрской ссылке |
| SRCH-10 | Сравнение с «прямым» вариантом: «на 9 800 ₽ дешевле, чем из Самары» |
| SRCH-11 | Поиск доступен и без регистрации, с параметрами, заданными в форме `[открыто]` |

## 3.4. Главная страница: горячие направления — v2

| ID | Требование |
|---|---|
| DEAL-1 | Топ направлений из домашнего города пользователя (и доступных хабов) по полной стоимости |
| DEAL-2 | Подсветка горячих предложений: «Москва: обычно 5 000 ₽, сейчас 1 000 ₽ (−80%)» |
| DEAL-3 | Базовая цена — медиана за 60 дней по накопленной истории; при нехватке истории — данные источника |
| DEAL-4 | Фоновое обновление цен по расписанию |

## 3.5. Гибкие даты — v2

| Режим | Описание |
|---|---|
| Точные даты | Туда — дата, обратно — дата (MVP) |
| Гибкие | «В ноябре, на 3–7 дней» → календарь цен и лучшие комбинации |
| Выходные и праздники | Длинные выходные из производственного календаря РФ |

## 3.6. Мультимодальность — v3

| ID | Требование |
|---|---|
| MM-1 | Поезда и автобусы как плечи маршрута (Самара → поезд → Саратов → самолёт) |
| MM-2 | Машина как первое плечо до любого хаба (аэропорт, вокзал, автостанция) |
| MM-3 | Склейка самостоятельных стыковок с запасом времени на пересадку |
| MM-4 | Зарубежные пересадки и хабы |

## 3.7. Пост-MVP — v4+

- Избранные направления и точки; постоянное отображение текущей цены по ним.
- Уведомления о падении цены (push в PWA, email; Telegram — позже).
- Страница пользователя: фото и посты из путешествий.
- Отзывы о точках с фото; карта, где по клику на город видны фото других путешественников.
- Модерация пользовательского контента.
