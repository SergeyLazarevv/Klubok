# Klubok

Сервис планирования путешествий, который считает **полную стоимость поездки «от двери до двери»**, а не только цену билета.

Пример: билет Самара → Алматы стоит 20 000 ₽. Но если у вас есть машина, можно доехать до Уральска и улететь оттуда за 5 000 ₽ — с бензином выйдет вдвое дешевле. Klubok находит такие варианты автоматически, комбинируя собственный автомобиль, поезда, автобусы и самолёты.
